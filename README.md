# 🌟 NomeDoApp //
> Frases motivacionais para estudantes com tradução em diferentes idiomas. Aprenda e inspire-se todos os dias.

## ✨ Sobre o projeto

Este app foi pensado especialmente para estudantes e pessoas apaixonadas por aprender. Sabemos como pode ser difícil manter a motivação, especialmente para quem enfrenta jornadas duplas entre estudo e trabalho.

A proposta do app é simples, mas poderosa: exibir frases motivacionais diárias com a opção de tradução para vários idiomas, promovendo o bem-estar emocional e o aprendizado de forma leve e integrada à rotina.

## 🎯 Objetivos

- Apoiar estudantes com mensagens que inspiram e motivam
- Ajudar no aprendizado de idiomas através de frases e expressões reais
- Criar um ambiente que conecta cultura, linguagem e desenvolvimento pessoal
